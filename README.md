# TF2-Paint-Program
Team Fortress 2-themed paint program. Inspired by MS paint. (2018)

## Running

Requires Python 3 with `tkinter` (bundled with most Python installs; on Debian/Ubuntu:
`sudo apt install python3-tk`).

```bash
pip install -r requirements.txt
python3 teamfortress2paintworkingversion.py
```

Run it from the repository root — the script loads `images/` and `songs/` via relative paths.
